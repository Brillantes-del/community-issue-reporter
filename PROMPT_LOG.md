# AI Prompt Log

This file documents the prompts used during the development of the Community Issue Reporter project.

## 1. Project Planning
**Prompt:**
Help me create a Community Issue Reporter web application for residents using HTML, CSS, JavaScript, and localStorage.

## 2. Initial Page Layout
**Prompt:**
Create a modern and simple HTML and CSS layout for a Community Issue Reporter website.

## 3. Report Form
**Prompt:**
Add a form where residents can submit an issue title, category, location, and description.

## 4. Issue Submission
**Prompt:**
Use JavaScript to handle the issue submission form and display a success message.

## 5. Display Reports
**Prompt:**
Display submitted community issues in a report list with their title, category, location, description, and status.

## 6. Data Persistence
**Prompt:**
Use browser localStorage to save submitted reports so they remain available after refreshing the page.

## 7. Form Validation
**Prompt:**
Add simple validation to make sure residents enter valid information before submitting a report.

## 8. Documentation
**Prompt:**
Help me write a README file explaining the project's purpose, users, features, technologies, and limitations.

## AI Usage
AI assistance was used to help plan the project, generate code suggestions, improve the layout, implement functionality, and prepare documentation. The generated code was reviewed and tested during development.
